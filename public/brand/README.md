# Brand assets

Official neuron-compact vectors, copied from the logo package. The app renders the
logo from `components/brand/Logo.tsx` (same geometry); these files are for
downloads, email signatures, and anything outside the React tree.

| File | Variant |
|---|---|
| `metadatum-mark.svg` | Primary, light background |
| `metadatum-mark-dark.svg` | Dark background (white chain, transparent) |
| `metadatum-mark-mono-black.svg` / `-mono-white.svg` | Monochrome |
| `metadatum-icon.svg` / `-icon-dark.svg` | Small-size icon (≤64px) |
| `metadatum-horizontal.svg` / `-dark.svg` / `-mono.svg` / `-mono-white.svg` | Horizontal lockups |
| `metadatum-stacked.svg` / `-dark.svg` | Stacked lockups |
| `metadatum-mark-512.png` | Raster mark for JSON-LD `logo` |
